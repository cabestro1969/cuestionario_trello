Ejercicio 1

Teoría de sistemas electrónicos

1,5 puntos

Explica con tus palabras qué diferencia hay entre una variable digital y una analógica. Pon un ejemplo de cada una e indica qué valores devuelve digitalRead() y qué rango de valores devuelve analogRead(). (1,5)

Solución modelo

Una variable digital solo toma dos estados: HIGH (5 V) o LOW (0 V), por eso digitalRead() devuelve 0 o 1. Ejemplo: un pulsador.

Una variable analógica puede tomar infinitos valores dentro de un rango continuo. Ejemplo: un potenciómetro o un termistor. En Arduino UNO, analogRead() convierte 0–5 V en un número de 0 a 1023 (10 bits).

Ejercicio 2

Ley de Ohm, resistencias y LED

1 punto

¿Para qué se coloca una resistencia en serie con un LED y qué puede pasar si se omite? (0,6)

Si en lugar de 150 Ω se usara una resistencia de 1 kΩ, el LED brillaría… (0,4)

Solución modelo

La resistencia limita la corriente que atraviesa el LED. Sin ella, la corriente es demasiado alta y el LED (y a veces el pin de Arduino) se quema o se destruye.

Con 1 kΩ: I = 3 V / 1000 Ω = 3 mA, mucho menos que los 20 mA de antes, así que el LED brilla menos.

Ejercicio 3

Estructura de un programa Arduino

2 puntos

a) Todo programa de Arduino tiene las funciones setup() y loop(). Indica a cuál corresponde cada afirmación. (1)

Solución

  • Se ejecuta una sola vez al encender o reiniciar: setup()
  • Se repite mientras la placa tiene corriente: loop()
  • Configurar los pines con pinMode(): setup()
  • Leer el pulsador y decidir qué hacer: loop()

b) Explica qué hace cada una de estas instrucciones. (1)

Solución modelo

  • analogRead(A0); lee el valor analógico del pin A0 y devuelve un número entre 0 y 1023.
  • analogWrite(9, 128); escribe una señal PWM en el pin 9. Con 128 (de un máximo de 255) equivale a la mitad de potencia.
  • Serial.println(valor); muestra el valor en el monitor serie y salta a la línea siguiente.
  • int contador = 0; declara una variable entera llamada contador con valor inicial 0.
Ejercicio 4

¿Qué hace este programa?

1,5 puntos

Un sensor magnético de puerta (reed switch) da HIGH cuando la puerta está abierta. Observa el programa y responde.

const int sensor = 4;
const int ledRojo = 12;
const int zumbador = 8;

void setup()
{
  pinMode(sensor, INPUT);
  pinMode(ledRojo, OUTPUT);
  pinMode(zumbador, OUTPUT);
}

void loop()
{
  if (digitalRead(sensor) == HIGH)
  {
    for (int i = 1; i <= 5; i++)
    {
      digitalWrite(ledRojo, HIGH);
      digitalWrite(zumbador, HIGH);
      delay(200);
      digitalWrite(ledRojo, LOW);
      digitalWrite(zumbador, LOW);
      delay(200);
    }
  }
  else
  {
    digitalWrite(ledRojo, LOW);
    digitalWrite(zumbador, LOW);
  }
}

a) Describe con tus palabras el funcionamiento completo del programa. (0,75)

Solución modelo

Si el sensor detecta la puerta abierta (HIGH), el LED rojo y el zumbador se encienden y se apagan a la vez 5 veces (bucle for), con 200 ms encendidos y 200 ms apagados. Si la puerta está cerrada (else), el LED y el zumbador permanecen apagados.

b) ¿Cuántas veces se enciende el LED en cada pasada del bucle for? (0,25)

Solución

5 veces: i va de 1 a 5.

c) ¿Cuánto tiempo dura el bucle for completo, en milisegundos? (0,25)

Solución

Cada vuelta: 200 + 200 = 400 ms. Cinco vueltas: 5 · 400 = 2000 ms (2 s).

d) ¿Qué ocurre mientras la puerta está cerrada? (0,25)

Solución

Se ejecuta el else: LED y zumbador apagados. Como loop() se repite, se vuelve a leer el sensor continuamente.

Ejercicio 5

Busca los errores

2 puntos

El siguiente programa debería encender un LED cuando se pulsa cualquiera de los dos pulsadores, pero no compila porque tiene 3 errores. Puedes tocar una línea para marcarla mientras buscas.

int pul1 = 2;
int pul2 = 3;
int led = 9;

void setup()
{
  pinMode(pul1, INPUT);
  pinMode(pul2, INPUT);
  pinMode(led, OUTPUT);
}

void loop()
{
  if (digitalRead(pul1) == HIGH || digitalRead(pul2) == HIGH
  {
    digitalWrite(led, High);
  }
  else
  {
    digitalWrite(led, LOW)
  }
}

a) Localiza los 3 errores indicando el número de línea y qué falla en cada uno. (0,9)

Solución

  • Línea 14: falta cerrar el paréntesis del if.
  • Línea 16: High está mal escrito; la constante es HIGH en mayúsculas.
  • Línea 20: falta el punto y coma al final de la instrucción.

b) Escribe cómo quedaría cada una de esas líneas corregida. (0,6)

Solución

if (digitalRead(pul1) == HIGH || digitalRead(pul2) == HIGH)
digitalWrite(led, HIGH);
digitalWrite(led, LOW);

c) Con el programa ya corregido, responde. (0,5)

Solución

|| significa «o»: basta un pulsador para encender el LED. && significa «y»: hacen falta los dos pulsados a la vez.

Ejercicio 6

Programa una puerta de garaje

2 puntos

Se dispone de un LED verde en el pin 6, un LED rojo en el pin 7, un zumbador en el pin 8 y un pulsador en el pin 2. Mientras el pulsador no esté pulsado, la puerta está cerrada y permanece encendido el LED verde. Cuando se pulsa, se apaga el verde y se encienden a la vez el rojo y el zumbador durante 4 segundos (la puerta se mueve). Después se apagan ambos y el sistema vuelve a evaluar el pulsador.

a) Escribe el programa completo (declaración de variables, setup y loop). (1,6)

El corrector busca cada pieza del programa (pines, pinMode, lectura, tiempos, orden). No lo ejecuta, así que compara siempre con la solución.

Solución modelo

const int pulsador = 2;
const int verde = 6;
const int rojo = 7;
const int zumbador = 8;

void setup()
{
  pinMode(pulsador, INPUT);
  pinMode(verde, OUTPUT);
  pinMode(rojo, OUTPUT);
  pinMode(zumbador, OUTPUT);
}

void loop()
{
  if (digitalRead(pulsador) == LOW)
  {
    digitalWrite(verde, HIGH);
  }
  else
  {
    digitalWrite(verde, LOW);
    digitalWrite(rojo, HIGH);
    digitalWrite(zumbador, HIGH);
    delay(4000);
    digitalWrite(rojo, LOW);
    digitalWrite(zumbador, LOW);
  }
}

Hay otras formas válidas, por ejemplo con if (digitalRead(pulsador) == HIGH) y el verde encendido en el else.

b) ¿Qué línea cambiarías para que la puerta tarde el doble de tiempo en moverse? Escríbela completa. (0,4)

Solución

Cambiar delay(4000); por delay(8000);.
