06Analiza el código: los primeros programas
13. Este es el programa Blink (encender y apagar un LED). Responde a las preguntas.
void setup() { pinMode(13, OUTPUT); } void loop() { digitalWrite(13, HIGH); // enciende el LED delay(1000); // espera digitalWrite(13, LOW); // apaga el LED delay(1000); // espera }
a) ¿Qué hace la instrucción pinMode(13, OUTPUT)?
b) ¿Qué unidad utiliza la función delay() y cuánto tiempo estará encendido el LED en cada ciclo?
c) Si cambiamos delay(1000) por delay(250) en ambas líneas, ¿qué efecto observaríamos en el LED?
